The urea concentration and uptake data were mainly downloaded from the Biological and Chemical Oceanography Data Management Office (BCO-DMO, https://www.bco-dmo.org/), British Oceanographic Data Centre (BODC, https://www.bodc.ac.uk), SeaDataNet (https://www.seadatanet.org/), PANGAEA (https://www.pangaea.de/), and Arctic Data Center (https://arcticdata.io/). Then, we checked the individual publications. When the cruise names (or the combination of observation period and area) were already in the data, which had already been downloaded from the websites, we did not include them. When data were presented as figures, they were obtained using a web-based data extraction tool (WebPlotDigitizer, https://automeris.io/wpd), or the data were not included in the dataset. When the urea concentration was reported as mol L-1 or M, we doubled the concentration to standardize it to urea-N. For the ammonium and nitrate, the data were downloaded in the same way, while the additional data on concentrations of nitrate and ammonium were obtained from Hansell et al. [2021] (for ammonium), GLODAP [Lauvset et al., 2024] (for nitrate), and GND-13 [Aoyama, 2020] (for nitrate). Here, GND-13 only provides the annual climatological concentration, and thus, we used it only when nitrate concentration at the same station was unavailable. Nitrate concentration was usually the sum of nitrite and nitrite. We excluded the data when the quality flag indicated poor quality. 

The authors originally described the R code, but Gemini curated it before publication.
